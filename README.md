# Expense Tracker

A personal expense tracker built with HTML, CSS and JavaScript.

**Live demo:** https://preethivishali15.github.io/expense-tracker

## Features
- Add income and expenses with category, date and note
- Total income, expenses and balance
- Filter by month and type
- Spending by category with percentage bars
- Data saved in the browser (localStorage)
- Responsive layout with light and dark mode

## Tech
HTML5, CSS3, JavaScript (ES6), localStorage, Intl.NumberFormat
